# 低代码字段级数据变更审计 Implementation Plan

**Goal:** 为在线低代码业务对象提供平台级字段变更审计：同事务采集真实前后值，详情页与管理员页共用查询。

**Architecture:** generator 独立 audit 领域负责策略、采集、差异和查询；动态 CRUD JDBC 写入口在事务收集器内捕获；Repository 对已启用对象缺失采集上下文失败关闭。前端共用 `components/data-audit` 与 Pinia store。

**Tech Stack:** Spring Boot 3、MyBatis XML、JDBC 动态 CRUD、Vue 3、Naive UI、Pinia、Flyway、JUnit 5、Vitest。

## 超级管理员审计范围修复（2026-09-20）

- [x] 根因定位：审计事件已成功落库，但超级管理员无显式角色范围时被解析为空集合，导致应用下拉和审计列表同时为空
- [x] 范围规则：超级管理员读取当前租户全部已配置策略对象，普通用户继续按角色审计范围授权

## 字段容量校验与时间轴可读性修复（2026-09-20）

- [x] 字段设计器：数字/金额直接配置最小值、最大值，decimal 明确配置总位数和小数位；文本继续配置最大字符数
- [x] 运行表单：把字段级 min/max/precision/maxlength 贯通到数字与文本组件，并限制在数据库列可存范围内

- [x] 其它组件：对多选、文件、图片等结构化值按序列化后的实际字符数执行列容量兜底
- [x] 模型发布：提前校验字符长度、decimal 总位数/小数位和 min/max 关系
- [x] 审计详情：时间轴默认加载并展示字段、修改前、修改后，主表变化优先，变化较多时可展开全部
