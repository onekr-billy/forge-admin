# 增量验证计划

## P0

- `git diff --check`：检查补丁格式和空白错误。
- 菜单模型 Vitest：覆盖权限过滤、顺序与元数据、`subapp`、直接入口、搜索、四级菜单和入口计数。
- 前端生产构建：验证新布局自动装配、Vue 模板和依赖引用。
- Flyway 静态检查：确认版本唯一、脚本无业务 `${...}` 占位符、迁移语句具备可重复语义。

## P1

- 对本轮新增与修改的 Vue/JS 文件执行 ESLint。
- 检查 `settings.js`、`.env`、租户编辑选项与迁移脚本的默认布局键一致。

## 本轮不执行

- 不连接或修改 Forge 线上数据库；本轮交付版本化迁移，由目标环境启动 Admin 服务时执行。
- 不启动完整后端；本轮后端仅新增 SQL，前端构建和 SQL 静态检查覆盖本次风险面。
