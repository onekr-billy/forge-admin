# Forge 业务工作台布局

## 状态

- 变更标识：`forge-business-workbench-layout`
- 当前阶段：已完成
- 目标分支：`main`

## 背景

LawHub 已完成一套顶部一级菜单与全宽分组菜单联动的新布局。Forge Admin 需要复用这套成熟交互，并去除法律业务专属命名和配色，使其成为适用于通用企业后台的默认布局。

## 目标

1. 新增通用布局 `business-workbench`，显示系统 Logo、标题、顶部一级菜单、搜索、主题、消息、布局设置和用户入口。
2. 一级菜单展开为同一全宽面板；左侧固定标题和搜索，二级菜单独立滚动；右侧按悬停、聚焦或点击的二级菜单显示其下级功能。
3. 菜单完全来自登录用户的权限菜单，保留原顺序、路由、图标、SSO 与打开方式，不注入示例菜单。
4. 支持直接入口、三级和四级菜单、菜单搜索、键盘操作、窄屏和顶部菜单溢出滚动。
5. 将布局名称统一为“业务工作台”，设为前端默认布局，并加入租户编辑的默认布局选项且标记为推荐。
6. 通过 Flyway 把 `sys_tenant.system_layout` 的数据库默认值改为 `business-workbench`，并把空值、`default` 以及默认租户的旧布局迁移为新布局。

## 约束

- 使用现有主题变量，主色跟随租户配置，不使用 LawHub 专属名称或固定法律业务配色。
- 共享菜单状态放入独立 Pinia store。
- 新布局通过现有 `import.meta.glob('./layouts/*/index.vue')` 自动装配，不修改动态路由和权限协议。
- `app-portal`、`empty` 等路由专用布局保持原语义。
- 数据库变更只新增版本迁移，不修改历史迁移。

## 验收标准

- 未配置租户布局时，登录后使用“业务工作台”。
- 租户编辑页能选择“业务工作台”，新建租户默认选中它，且只有该布局显示“推荐”。
- 顶部一级菜单切换时复用同一面板容器，没有重复遮罩闪烁；当前路由标记与悬停展开状态互不串扰。
- 桌面端菜单面板稳定显示在当前父级菜单下方，使用固定高度和一致宽度；切换父级时不跳位，内容始终可滚动访问。
- 左侧搜索、标题固定，二级菜单可滚动；无下级菜单不显示箭头；四级菜单层次可辨。
- 前端布局单测、静态检查和生产构建通过。
- Flyway 脚本版本唯一，无 `${...}` 占位符，数据库默认值与默认租户数据均指向 `business-workbench`。

## 影响与回滚

- 影响范围：Forge Admin 布局装配、租户外观配置、`sys_tenant.system_layout` 默认值。
- 兼容性：已有租户的明确非默认布局保持不变；默认租户切换到新布局。
- 回滚：前端可把 `defaultLayout` 和环境默认值恢复为旧布局；数据库需新增更高版本迁移恢复列默认值和租户配置，禁止回改已执行脚本。

## 验证结论

- 菜单模型与默认布局单测共 12 项通过。
- 本轮 Vue、JS、CSS 文件 ESLint 通过。
- Vite 生产构建通过，生成 `business-workbench` 独立布局产物。
- Flyway `1.0.181` 版本唯一，脚本无 Flyway 业务占位符。
