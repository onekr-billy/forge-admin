# 文件管理页面简化

## 目标与范围

优化 `/system/file-list` 的视觉层级、操作组织和空间利用。使用项目主题与 MasterDetailWorkspace 连体工作台，保留上传、预览、下载、搜索、分组、重命名、复制链接、移动与删除能力。只修改本页及同域组件、store，不修改后端、权限、数据库或其它页面。

## 设计

- 去掉装饰页头、重复统计、重复视图切换、无实际区别的“最近上传”、无对应批量动作的复选框、密度/全屏等通用工具按钮。
- 左侧显示全部文件、图片、文档及自定义分组；右侧单一标题、上传主按钮、一行搜索工具栏与内容。
- 文件名结合轻量缩略图/中性色类型图标；主列表只保留名称、大小、存储类型、上传时间、操作。
- 预览/下载常用动作直显，重命名、复制链接、移动、删除放入三点菜单，不重复常用动作。
- 列表、网格共用 Pinia 数据/筛选/分页；接口参数使用 pageNum/pageSize；切换分类回到第一页，处理请求竞态，避免过时响应覆盖当前分类。
- 低频的业务类型、存储类型筛选收进筛选浮层；有生效筛选时给出可见标识和清除入口。
- 采用主题变量、小圆角、细边框，不使用渐变、彩色装饰块、重阴影或持续动效。
- 组件均低于 800 行；图片使用 AuthImage；分组/存储字典沿用已有 useDict。

## 验收与风险

- 亮色、暗色、窄屏无页面横向溢出，文件列表及分组可独立滚动。
- 搜索、分类、分页、视图切换与文件菜单在浏览器模拟 API 下验证。
- 删除继续保留确认框；本轮不在真实环境执行上传/删除等数据写入。
- 本地无运行中的后端服务，浏览器验证使用独立入口与模拟 API，并明确不等同于真实后端联调。
- 构建、定向 ESLint、git diff --check 必须通过；结果与警告记录到 execution-log.md。
