# 低代码应用：集成与开放

## 目标与范围
- 在应用设计器的设置中增加“集成与开放”，企业协同、对外能力、接入授权、调用记录四个页签；不修改 H5 工作树。
- 企业协同绑定租户内已有连接，只保存引用，不复制凭据。显示 LOGIN/MESSAGE 配置可用性（不代表外部平台连通性已验收）；生成 PC 门户免登入口和应用专属消息通道。仍须显式配置模板和发送消息步骤，接收人按下述范围处理，不自动添加通知。钉钉、飞书、企业微信 TODO 同步不在本期。
- 能力注册复用现有三步注册器，锁定当前应用；流程/表单/业务动作仅允许已发布应用包含的对象。REST 仍仅允许显式纳管接口。发布与应用关联同事务。
- 新业务流程的 SEND_MESSAGE 节点支持站内信或本应用协同连接，接收人明确为流程发起人，使用运行实例+节点幂等键。存量触发器/业务动作继续保留其接收人规则；不宣称本期已提供新的任意收件人设计器。
- 应用能力目录由服务端按租户/应用关联分页；授权和调用记录按选定的应用能力查询，禁止空选择退化成全局列表。复用现有调用指南与权限、身份、版本、审计链路。
- 应用绑定配置独立于草稿/发布快照，保存立即生效，采用 revision 乐观并发。已发布能力采用独立不可变版本，不因重新发布应用自动更新。

## 安全与人工审查门槛
- 配置写入同时要求应用编辑及协同配置权限；能力发布/授权/日志同时要求应用访问与原开放平台权限。不得因应用编辑权取得全局开放权限。
- 所有查询显式 tenant_id，来源采用正式应用快照校验，应用内发布不能更新其他应用的同名能力。
- 消息连接被停用/跨租户/解绑必须失败关闭，不退回默认连接或站内信；仅发送已配置规则产生的消息。
- URL 仅使用本站门户地址及后端连接编码，无密钥；免登继续服务端 OAuth state/一次性票据，应用可见性不绕过。
- 免登授权与回调同时校验连接启用和工作台免登开关；保存/恢复应用深链不跳转到外站。应用解绑只停用应用消息通道，不撤销平台连接、已有登录会话或已分发链接的中央登录资格。
- 审批异步回调可使用已验证的 TenantContextHolder 租户，无交互会话不伪造用户；缺少租户或处于忽略租户模式时拒绝企业协同消息。
- 涉及授权、外部消息和数据库迁移，部署前由人工审查。此次不运行数据库/真实发信/真实授权，不启动 Admin/Flow。

## 数据及兼容
- V1.0.183 新增应用集成配置、应用能力关联（审计字段、utf8mb4、逻辑删除预留及活跃唯一键）；不改历史迁移、不初始化演示/日志数据。

## 验收
入口可发现、切换应用无旧请求污染、未发布/无权限/空态/错误可解释；小屏及深色可读；取消不写入；保存/发布/授权防双击；跨应用/租户拒绝；消息真实经过 COLLABORATION 链路。

## 本地增量收尾（2026-09-22）
- 配置刷新不得覆盖正在编辑的连接选择；保存开始后，之前的读取响应失效，保存中不再启动同域配置刷新。
- 消息执行前重新确认模板仍启用；发布后模板被停用或删除必须明确失败，不创建空消息。
- 应用专属通道类型漂移、企业协同开关不是布尔值或节点缺失稳定 ID 时拒绝执行，不静默降级为站内信或共享错误幂等键。
- 只做本地代码、定向测试及组件回归；真实环境验收门槛不变。
