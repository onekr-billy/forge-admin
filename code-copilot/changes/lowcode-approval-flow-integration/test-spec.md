# 低代码审批流程衔接优化 Test Spec

## P0 自动化验证

1. 审批节点配置只发出一次打开事件，DOM 中不存在本地流程设计器遮罩。
2. 新建模型后配置立即包含字符串模型 ID、Key、名称，并保留待发布选项。
3. 已发布目录与当前草稿选项状态区分正确。
4. 内嵌业务流程工作台只有一个 `FlowDesignPage` 所有者；保存/部署刷新目录，关闭才隐藏弹窗。
5. Flow 模型目录默认只查已发布，`includeDraft=true` 返回全部未删除模型，`status` 条件可用。
6. Generator 的设计目录请求草稿，发布校验目录只请求 `status=1`。

## P1 构建验证

- 前端相关 Vitest。
- Flow 插件与 Generator 相关 Maven 定向测试。
- Flow Server/Generator 依赖链编译。
- 前端生产构建。
- `git diff --check`。

## 跳过项

- 不启动真实 Admin/Flow 服务，不写入本地或远程数据库。
- 不执行真实浏览器端到端部署；以组件交互测试和构建验证覆盖本轮回归，真实环境由部署后人工复验。
