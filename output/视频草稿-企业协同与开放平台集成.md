# 视频口播草稿：Forge Admin 企业协同 + 开放平台集成

> 纯口播稿，不含分镜。按正常语速约 240 字/分钟估算，全文约 1100 字，时长 4 分钟以上，可按需删减。

大家好。最近我给 Forge Admin 完成了两个大模块的集成：企业协同平台对接，和能力开放平台。这期视频就聊聊它们能做什么，以及我在设计上的取舍。

先说企业协同。这次完整打通了企业微信：扫码登录、通讯录同步、消息推送、待办卡片、回调事件，五条能力线一次交付。架构上是平台无关的，底层是一套 Provider SPI 加注册表，企业微信是第一个适配器，钉钉和飞书的扩展点已经预留在那里，后续接入不用动编排层。

登录这块我做了一个比较克制的决定：不允许自动建号。员工第一次扫码登录前，必须先跑过通讯录同步、建立身份映射，否则直接拒绝。宁可多一步管理动作，也不要系统替你猜这个扫码的人是谁。通讯录同步走的是快照校验加差量写入，没在企业微信里出现的账号只停用、不删除，绝不碰你在 Forge 里手工配置的岗位和角色。同步失败了也不慌，问题会进问题单，人工选择绑定、忽略或者重试。

消息侧，消息中心新增了统一的协同渠道，审批待办会直接变成企业微信里的卡片，点卡片深链跳到 H5 详情页就能办理。卡片文案是模板驱动的，每个平台可以不一样。投递是逐接收人记录状态的，失败的有补偿任务兜底——回调重试、投递补偿、每日全量校准，三个内置定时任务加指数退避，企业微信抖动不会让消息悄悄丢掉。

再说开放平台。一句话：把 Forge 的能力以标准 API 的形式开放给外部系统。统一入口，一次调用走完整条链路——认证、防重放、授权、限流、幂等、参数校验、执行、审计。客户端接入支持三种身份：OAuth 客户端凭证、HMAC 请求签名，还有用户委托。用户委托是我觉得最值得说的：外部系统可以拿 OIDC Token 交换，也可以用 RSA 私钥签一个用户断言，Forge 只存公钥，断言两分钟过期、一次性使用，调用方永远不许自己传 userId——身份只能被证明，不能被声明。

开放的能力来自三个地方：低代码业务动作、流程动作、系统服务。也就是说，你在外围系统里调一个接口，就能完成低代码建单加发起审批，然后你公司的员工在企业微信里收到待办卡片点开办理。外部接入、流程流转、员工触达，这条端到端的链路，这次是真正通了。

配套体验也做了不少：能力目录有版本管理，客户端可以固定版本或者跟随大版本；调用指南会逐项诊断你为什么还调不通；在线测试走的是真实链路，没有测试后门，报文可以下载下来排障；还能一键导出中文的 Markdown 调用文档和 OpenAPI 3.1 描述文件。

最后说安全，因为这两个模块本质上都在开边界。密钥全部 AES-GCM 加密落库，私钥和签名密钥只在创建时展示一次；出站请求走白名单；日志和审计全程不落密钥和敏感信息。规模上，这次一共十八个数据库迁移脚本、协同侧七十多个后端类、十几个管理页面。

这两个模块都已经进了主干。感兴趣的朋友可以去仓库看变更文档，也欢迎在评论区聊聊你们在企业微信集成上踩过的坑。我们下期见。
