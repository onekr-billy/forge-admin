### config 模块核实结果（2379 行 main / 200 行 test，两套体系）
体系 A `config/`：配置中心（SysConfigGroup CRUD / ConfigManagerService / ConfigCenterService / ConfigSyncService / ConfigConverter JSON拍平 / CryptoConfigSanitizer）
体系 B `property/`：动态刷新（DbPropertySourcePostProcessor / DbConfigLoader / DbPropertySource / ConfigRefresher / ConfigChangeListener / RefreshScopeImpl / ConfigRefreshEvent / ConfigRefreshController）

### 5 个坑（全部源码核实）
1. **【最狠】`ConfigChangeListener.checkAndRefresh()` 的 `@Scheduled` 被注释掉**（方法体 log.debug 也注释了）→ **"30秒自动刷新"从未生效**，只能手动 POST `/api/config/refresh`。而 `AppConfigExample` 类注释白纸黑字写着"30秒内自动刷新"→ **文档与实现对不上**。且类上 `@ConditionalOnProperty(auto-refresh, matchIfMissing=true)` 还在，给人"功能工作中"的错觉；`PropertyRefreshAutoConfiguration` 上 `@EnableScheduling` 开着却无任务
2. **刷新边界**：`refreshAll()` 只清 `scopedObjects` 缓存 → 只有 refresh scope 的 Bean 重建。**普通单例 + `@ConfigurationProperties`（无 @RefreshScope）不刷新；单例里 `@Value` 字段永远不变**
3. **`ConfigRefreshEvent` 是死类**：定义了 + 有 `getChangedProperties()`，但 `refresh()` 里 `//publishRefreshEvent(...)` 是注释状态，从未发布。`publishEnvironmentChangeEvent` 方法体整个被注释（兼容 Spring Cloud 的 EnvironmentChangeEvent 也没发）
4. **`DbPropertySource` 用 `addFirst` 注册 → 优先级高于 application.yml/环境变量/命令行**，库里配错本地救不回来
5. **要单独配一套 `config.datasource`**（第二套数据源）。`DbPropertySourcePostProcessor` 是 EnvironmentPostProcessor，容器启动前自己造 DataSource；**没配就静默 return，不报错**（很容易漏）；加载失败抛 RuntimeException 阻断启动

### 做得对的地方
- **自定义 `@RefreshScope` 的 `proxyMode = ScopedProxyMode.TARGET_CLASS`**（`core/annotation/config/RefreshScope.java`）——这是方案能工作的关键。Spring 原生 `@Scope` 默认 `ScopedProxyMode.DEFAULT`（等同不代理），若那样注入裸对象则刷新完全失效且不报错
- **两表合并 + 分组覆盖**：`loadSysConfig`(sys_config, config_type='Y') → `loadConfigGroups`(sys_config_group, status=1, JSON拍平) → 驼峰变体（`max-login-attempts` → `maxLoginAttempts`）
- **三层降级不阻断**：sys_config 失败→降级旧表 config_properties；group 表不存在→warn 跳过不影响基础层；单分组 JSON 失败→跳过该分组
- **crypto 部署密钥过滤**：`CryptoDeploymentSecretPolicy.isDeploymentSecretPropertyKey(key)` → 数据库不能覆盖部署级密钥（否则拿库写权限=拿解密能力）
- `refresh()` 是 `synchronized` + 先 diff（无变化直接 return false）
- 刷新端点有 `SessionHelper.assertAdmin`，但 `@ConditionalOnProperty(enable-refresh-endpoint, matchIfMissing=true)` **默认开启**
