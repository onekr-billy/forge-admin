### 本片核心素材（全部实测源码，后续可复用）
- 注解在 starter-core：`core/annotation/crypto/ApiEncrypt.java`、`ApiDecrypt.java`；`@CryptoField` 与 `@Desensitize` 在 crypto 模块内
- **密文版本化是全文最值钱的设计**：`PersistentCiphertext` record，格式 `FPC1:{算法}:{keyId}:{密文}`（split(":",4)），inspect() 五态分类 LEGACY/ACTIVE/HISTORICAL/UNKNOWN_KEY/UNKNOWN → decrypt 按态走不同路径 → reencrypt() 渐进迁移不用全表重写；CryptoMigrationReport 迁移进度可视化
- 算法枚举：SM4(国密,fromCode(null)默认SM4)/AES/AES_GCM(认证加密)；EncryptorFactory ConcurrentHashMap 注册表，算法运行时可选
- 请求解密 DecryptRequestBodyAdvice：supports 四级判断（总开关→明文控制端点/crypto/config→InternalCallRequestVerifier内部调用→ApiConfigManager动态配置优先否则@ApiDecrypt 类/方法）；算法三级优先级（注解>请求体>全局）；DecryptedHttpInputMessage 偷换 body 流
- 响应加密 EncryptResponseBodyAdvice：跳过 ResponseEntity<byte[]>（ParameterizedType 泛型反射）；ExcludePaths 用 AntPathMatcher
- 会话密钥：SessionKeyStore Redis `crypto:session:{sessionId}` TTL 2h；会话标识三级回退 Authorization Bearer > X-Session-Id > HTTP Session
- 防重放 ReplayAttackFilter：X-Timestamp+X-Nonce，时间窗 Math.abs 正负偏差；**nonce TTL = 2×窗口**（注释原文"避免边界重放"）；/ws 前缀跳过
- 字段级：CryptoFieldSerializer 实现 ContextualSerializer 拿注解算法；**fail-closed**（加密失败抛 IOException 拒绝输出原文）
- 脱敏：@Desensitize（@JacksonAnnotationsInside）+ 8 策略工厂（PHONE/ID_CARD/EMAIL/BANK_CARD/NAME/ADDRESS/PASSWORD/CAR_LICENSE）+ CUSTOM prefixKeep/suffixKeep/replaceChar
- 6 条踩坑清单（线上级）：会话密钥过期无自动重协商/二进制响应乱码/nonce TTL 边界漏洞/内部调用被强解/静默降级明文/控制面死锁
